# Accepted Euler search evidence

The current combined finite-coverage ledger is [index-p16.json](index-p16.json).
It includes the accepted P14, P15 and P16 experiments and lists unsearched
regions explicitly. The detailed P16 result is in
[POST_BRAUN_P16.md](../../docs/POST_BRAUN_P16.md).

[index.json](index.json) is the unchanged P14/P15 baseline used as a hashed
input to P16. Its remaining-work examples describe that historical stopping
point; use the superseding ledger for current coverage. Original ZIPs and
receipts retain their exact bytes and source identities. Compressed job logs
preserve observed runtime, memory and formal verification output.

None of these restricted cells is a complete high-height or general signed
census. Algebraically excluded c prefixes are distinguished from enumerated
(c,abs(a)) trials. Zero witnesses in a listed cell does not prove global
nonexistence.
